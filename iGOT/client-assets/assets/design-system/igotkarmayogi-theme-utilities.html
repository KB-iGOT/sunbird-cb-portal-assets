Theme-Aware Utility Classes

Classes that automatically adapt between light and dark modes — click any class name to copy it

1 How It Works

Zero code theme-switching via custom properties internally resolved by [data-theme]

These utility classes wrapper standard elements and automatically map standard states between light and dark configurations. When data-theme="dark" is toggled on the main html document, the resolved variables flip transparently.
